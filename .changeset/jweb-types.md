Initial release: type declarations for `window.max`, the MaxBridge API of web pages loaded in Max's `[jweb]` object. `MaxBridge`, `MaxDict`, `MaxArray`, `JitterMatrix`, `JitterImage` and the streaming types are exported from the main entry; the `max` global is declared by `@tsln/jweb-types/global`, listed in `types`.
